Spotlight: Noctis AI Study Assistant

Revolutionizing Student Academic Support

Noctis is my flagship project - an AI-powered study assistant that I built to solve a problem I faced as a student: managing coursework, assignments, and deadlines across multiple platforms was overwhelming.

Key Features:

  • AI Chat Assistant: Real-time homework help powered by locally-running Hermes AI model
  • Canvas LMS Integration: Automatic course, assignment, and grade synchronization
  • Google Calendar Sync: View and create calendar events directly from the chat interface
  • WhatsApp Support: Get study help on-the-go through WhatsApp messaging
  • Study Tools: Generate flashcards, quizzes, and Jeopardy-style review games
  • GPA Calculator: Track academic performance with automatic Canvas grade syncing

Technical Implementation:

Built with Node.js and Express, Noctis uses Google OAuth 2.0 for secure authentication, integrates with Canvas LMS and Google Calendar APIs, and employs AES-256-GCM encryption to protect user data. The AI backend runs on a locally-hosted Hermes model, ensuring privacy and fast response times.
